# 코딩할고양

고양 청소년어울림마당에서 아이들이 명령 블록으로 고양시 마스코트의 이동 경로를 설계하는 5단계 웹게임입니다. 폭탄을 피하고 코인을 모아 깃발에 도착하면 서버가 경로를 다시 검증하고 점수를 계산합니다.

주최·협력 로고와 공식 캐릭터 원본은 프로젝트 안에 포함되어 있습니다. 캐릭터는 고양특례시 제공 자료이며 `공공누리 제3유형` 조건에 따라 원본 형태를 유지하고 출처를 표시합니다. 제작: 연세대학교 컴퓨터과학과 조민준.

구현 결정, 운영 방법, 원본 이미지 위치와 최종 확인 항목은 [프로젝트 전달사항](HANDOFF.md)에 정리되어 있습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 연 뒤:

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 열면 메인 페이지가 나오며, `대회 시작하기`를 누르면 경기장으로 이동합니다. 같은 네트워크의 다른 기기에서는 서버 컴퓨터의 IP 주소와 포트 `4173`을 사용합니다.

## 경기 규칙

- 다섯 스테이지를 순서대로 완료합니다.
- 프로그램은 삭제할 수 없는 `시작` 블록에서 출발합니다.
- 사용할 수 있는 명령은 `위로`, `아래로`, `왼쪽`, `오른쪽`, `반복하기`뿐입니다. 캐릭터 회전은 없습니다.
- 명령 창고의 블록을 왼쪽 알고리즘 창으로 드래그하거나 클릭해서 조립할 수 있습니다.
- 명령 창고는 동일한 정사각형 블록과 브라우저에서 깨지지 않는 SVG 방향·반복 기호를 사용합니다.
- ㄷ자 반복 블록 안에 방향 블록을 끼워 넣고 반복 횟수를 2~6회로 조절할 수 있습니다.
- 실행 전 예상 경로는 지도에 표시하지 않으며, 실행 중인 블록과 실제 이동 결과만 보여줍니다.
- 스테이지별 블록 개수 제한은 없습니다.
- 같은 경로라면 명령 블록을 적게 쓸수록 높은 점수를 받으며, 완료 시간도 점수에 반영됩니다.
- 코인 하나마다 700점의 보너스를 받습니다.
- 폭탄이나 벽에 닿은 실행은 실패하며 프로그램을 고쳐 다시 실행할 수 있습니다.
- 5단계 완료 뒤에만 이름을 입력하고 순위표에 등록할 수 있습니다.
- 서버가 제출된 명령을 직접 재실행해 실제 깃발 도착 여부와 코인 수를 검증합니다.

## 주요 파일

- `public/index.html`: 대회 메인 페이지
- `public/game.html`: 블록 코딩 경기 화면
- `public/home.css`, `public/home.js`: 메인 페이지와 스테이지 미리보기
- `public/styles.css`: 반응형 디자인과 게임 표현
- `public/stages.js`: 클라이언트와 서버가 함께 사용하는 5개 스테이지 배치
- `public/app.js`: 블록 실행과 게임 상태
- `server.mjs`: 정적 파일, 서버 채점, 순위표 API
- `data/scores.json`: 최대 100개의 순위 기록
- `public/assets/branding/`: 행사·기관·PROTEEN 로고
- `public/assets/goyang-cat-*.png`: 고양특례시 공식 캐릭터 원본

## 운영 전 확인

- 1·2단계의 3×3 맵은 5×5 중앙에 배치하고 바깥 한 칸을 벽으로 둘렀습니다.
- 전달된 5단계 원본은 시작 지점의 출구가 폭탄으로 모두 막혀 있어, 진행 가능하도록 시작점 바로 위 폭탄 한 개를 제외했습니다.
- 경기 화면은 1920×1080에서 왼쪽 알고리즘, 오른쪽 지도, 하단 명령 창고가 한 화면에 들어오도록 설계했습니다.
- `data/scores.json`을 `[]`로 비우면 순위표를 초기화할 수 있습니다.
- 행사 규칙에 맞춰 점수 공식을 바꾸려면 `server.mjs`의 `stageScore` 계산식을 수정합니다.
- 여러 행사 서버가 동시에 필요하면 각 서버는 별도의 순위표 파일을 사용합니다.
