# 코딩할고양

고양 청소년어울림마당에서 아이들이 명령 블록으로 고양시 마스코트의 이동 경로를 설계하는 웹게임입니다. 중급 또는 고급 미션의 세 단계를 선택해 진행하며, 폭탄을 피하고 코인을 모아 깃발에 도착하면 브라우저에서 점수를 계산합니다.

주최·협력 로고와 공식 캐릭터 원본은 프로젝트 안에 포함되어 있습니다. 캐릭터는 고양특례시 제공 자료이며 `공공누리 제3유형` 조건에 따라 원본 형태를 유지하고 출처를 표시합니다. 제작: 연세대학교 컴퓨터과학과 조민준.

구현 결정, 운영 방법, 원본 이미지 위치와 최종 확인 항목은 [프로젝트 전달사항](HANDOFF.md)에 정리되어 있습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 연 뒤:

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 열면 메인 페이지가 나오며, `미션 시작하기`를 누르면 미션 화면으로 이동합니다. 같은 네트워크의 다른 기기에서는 서버 컴퓨터의 IP 주소와 포트 `4173`을 사용합니다.

## 미션 규칙

- 시작할 때 `중급 미션(기존 1·2·3단계)` 또는 `고급 미션(기존 3·4·5단계)`을 선택합니다.
- 프로그램은 삭제할 수 없는 `시작` 블록에서 출발합니다.
- 사용할 수 있는 명령은 `위로`, `아래로`, `왼쪽`, `오른쪽`, `반복하기`뿐입니다. 캐릭터 회전은 없습니다.
- 명령 창고의 블록을 왼쪽 알고리즘 창으로 드래그하거나 클릭해서 조립할 수 있습니다.
- 명령 창고는 동일한 정사각형 블록과 브라우저에서 깨지지 않는 SVG 방향·반복 기호를 사용합니다.
- ㄷ자 반복 블록 안에 방향 블록을 끼워 넣고 반복 횟수를 2~6회로 조절할 수 있습니다.
- 실행 전 예상 경로는 지도에 표시하지 않으며, 실행 중인 블록과 실제 이동 결과만 보여줍니다.
- 기존 1~5단계의 블록 제한은 각각 `8, 9, 9, 10, 12개`이며 반복 블록 내부 명령도 개수에 포함됩니다.
- 각 단계는 G메타 행사 버전에서 실제 사용한 8개 배치 중 하나를 미션 시작 때 선택합니다.
- 같은 경로라면 명령 블록을 적게 쓸수록 높은 점수를 받으며, 완료 시간도 점수에 반영됩니다.
- 코인 하나마다 700점의 보너스를 받습니다.
- 폭탄이나 벽에 닿은 실행은 실패하며 프로그램을 고쳐 다시 실행할 수 있습니다.
- 선택한 미션의 3단계를 완료하면 총점, 기록, 코인 수를 결과 화면에서 확인할 수 있습니다.
- 순위표와 개인정보 입력 없이 각 기기에서 미션을 바로 시작할 수 있습니다.

## 주요 파일

- `public/index.html`: 미션 메인 페이지
- `public/game.html`: 블록 코딩 미션 화면
- `public/home.css`, `public/home.js`: 메인 페이지와 스테이지 미리보기
- `public/styles.css`: 반응형 디자인과 게임 표현
- `public/stages.js`: G메타 당시의 5단계·단계별 8개 배치와 블록 제한
- `public/app.js`: 블록 실행과 게임 상태
- `server.mjs`: 로컬 실행용 정적 파일 서버
- `public/assets/branding/`: 행사·기관·PROTEEN 로고
- `public/assets/goyang-cat-*.png`: 고양특례시 공식 캐릭터 원본

## 운영 전 확인

- 실제 플레이 맵 크기는 1·2단계 3×3, 3·4단계 5×5, 5단계 7×7이며 각 단계에 G메타 당시 배치 8개가 들어 있습니다.
- 미션 화면은 1920×1080에서 왼쪽 알고리즘, 오른쪽 지도, 하단 명령 창고가 한 화면에 들어오도록 설계했습니다.
- 행사 규칙에 맞춰 점수 공식을 바꾸려면 `public/app.js`의 `stageScore` 계산식을 수정합니다.
- 미션 데이터와 점수 계산은 모두 프론트에 들어 있으며 API, 데이터베이스, 환경변수가 필요하지 않습니다.
